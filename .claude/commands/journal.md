오늘의 개발 일지를 작성한다.

1. 오늘 날짜(Asia/Seoul)로 `docs/일지/YYYY-MM-DD.md` 경로를 정한다. 파일이 이미 있으면 기존 내용 아래에 이어서 추가한다.
2. `docs/일지/_TEMPLATE.md` 양식을 따른다.
3. 다음 자료를 바탕으로 채운다.
   - `git log --since=midnight --stat` 결과
   - 커밋되지 않은 변경은 `git diff --stat`
   - 오늘 이 세션에서 나눈 대화와 결정 사항
4. "한 일"은 작업 단위로 번호를 매기고, 각 항목은 한 줄 제목 + 짧은 불릿 2~4개로 쓴다. 긴 문단으로 쓰지 않는다. 대화 내용을 근거로 구체적으로 쓰고, 근거가 없으면 비워두고 추측하지 않는다.
5. "다음 할 일"은 오늘 끝내지 못한 작업과 대화에서 나온 후속 작업으로 채운다.
6. 비밀번호, API 키, 사용자 위치 정보는 일지에 쓰지 않는다.
7. 작성 후 요약을 3줄로 보여주고, 사용자가 확인하면 저장한다.
